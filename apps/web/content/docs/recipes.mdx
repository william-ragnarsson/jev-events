Recipes are plain question objects exported as `recipes`. Each asks one narrow judgment and spells out its outcomes, following [TypeSafe's guidance](https://docs.typesafe.ai/primitives). Use them as they are, or copy one and change the wording.

```ts
import { monitor, recipes } from "jev-events";
import { twitch } from "@jev-events/twitch";

const chat = monitor({
  source: twitch.chat(),
  questions: { kind: recipes.chat.kind, hateful: recipes.chat.hateful },
});
```

The question id is yours to choose. `{ hate: recipes.chat.hateful }` fires `"hate"` instead of `"hateful"`.

Thresholds are yours too. The chat recipes `kind`, `hateful`, `question`, `streamIssue` and `spam` are scored on the [benchmarks](/docs/benchmarks) page, which shows precision and recall at each threshold. The others haven't been benchmarked yet, so measure them on your own data before acting on them automatically.
