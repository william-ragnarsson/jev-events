**No code first?** `npx jev-events watch twitch:<any live channel>` prints what Jev says about each chat message in your terminal, with no Twitch account. `watch gmail`, `watch calendar` and `watch slack` work the same once you install the integration and sign in with `auth google` or `auth slack`. See [the CLI](/docs/cli).

<Steps>

## Install

Jev Events needs Node.js 22 or newer. Make a folder, and install it with `tsx`, which runs TypeScript:

```bash
mkdir my-monitor && cd my-monitor
npm init -y && npm pkg set type=module
npm i jev-events tsx
```

## Add your TypeSafe key

Get an API key from [TypeSafe](https://docs.typesafe.ai/introduction/quickstart) and put this line in a file called `.env` next to your code:

```dotenv title=".env" mark="<your key>"
TYPESAFE_API_KEY=<your key>
```

## Run it

```bash
npx tsx --env-file=.env monitor.ts
```

```txt
[question] mira_plays: what rank are you now?
[question] bytebandit: is this the new patch?
[hateful] anon_4412 (0.94)
```

Questions for the streamer are printed as they arrive, and so are hateful messages Jev is at least 90% sure about. Stop it with Ctrl+C.

## Moderate your own channel

To act in chat, the monitor has to read it as you. Install the Twitch integration and sign in once:

```bash
npm i @jev-events/twitch
npx jev-events auth twitch
```

The first time, `auth twitch` walks you through registering your own Twitch app, then shows a code to approve on Twitch. The sign-in is saved in `.jev-events/`, which git ignores. Then read your own channel and add a native action:

```ts title="monitor.ts" mark="twitch.chat()|twitch.timeout({ seconds: 600 })"
import { monitor, recipes } from "jev-events";
import { twitch } from "@jev-events/twitch";

const mods = monitor({
  source: twitch.chat(), // your own channel, as you
  questions: { hateful: recipes.chat.hateful },
}).on("hateful", { min: 0.9 }, twitch.timeout({ seconds: 600 }));

await mods.start();
```

Run it the same way. Native actions start in dry-run, so the timeout only prints what it would do:

```txt
[jev-events] [dry-run] would timeout viewer_42 for 600s (hateful p=0.97)
```

When those lines look right, pass `dryRun: false` to `monitor()`. The [Twitch guide](/docs/integrations/twitch) covers every action, and its builder writes the code for the questions and actions you pick.
