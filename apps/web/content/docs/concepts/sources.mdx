A source connects to a stream and emits **items**. Every item has the same small shape, whatever the platform:

```ts
interface Item {
  id: string; // unique within its source
  text: string; // what Jev judges
  author?: { id: string; name: string; roles?: string[] };
  at: Date; // when it was created at its origin
  // Lean facts shown to Jev, such as { firstMessage: true }
  facts?: Record<string, JsonValue>;
  raw?: unknown; // the original payload; never sent to Jev
}
```

Connectors add typed fields on top. A Twitch chat item also has `channel`, `firstMessage`, `reply` and `bits`, and your handlers see them with full types.

## Built-in sources

| Source | Package | Notes |
| --- | --- | --- |
| `twitch.chat(channel, { auth? })` | `@jev-events/twitch` | Read-only without `auth`; can moderate with it. [Guide](/docs/integrations/twitch) |
| `from(iterable, options?)` | `jev-events` | Any iterable or async iterable of strings or objects |
| `webhook(options?)` | `jev-events` | Items arrive as HTTP POSTs |
| `bluesky(options?)` | `jev-events/public` | The public Bluesky firehose, read-only |
| `twitchChat(channel)` | `jev-events/public` | Anonymous, read-only Twitch chat with no extra package |

## `from()`

Wrap anything you can iterate: log lines, a queue consumer, rows from a database cursor. Strings become items directly; objects can carry an `id`, `author`, `at` and `facts`.

A finite iterable ends the source when it runs out, so `await listener.run()` judges everything and returns the stats. That makes `from()` handy for backfills and [tests](/docs/testing).

## `webhook()`

Starts a small HTTP server. POST a string, `{ "text": "..." }`, or an array of them:

```bash
curl -X POST http://127.0.0.1:8787/ \
  -H "Authorization: Bearer $WEBHOOK_SECRET" \
  -d '{"text": "Your product broke my build again and nobody answers"}'
```

## Write your own

A source is a plain object with an `id`, a `platform` and a `start(ctx)` that emits items. `start` resolves once the source is connected and keeps emitting until `ctx.signal` aborts.
