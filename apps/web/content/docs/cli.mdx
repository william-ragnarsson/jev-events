The `jev-events` command ships with the library, so `npx` runs it without installing anything. It needs your TypeSafe API key: put `TYPESAFE_API_KEY=<your key>` in a `.env` file, or paste the key when it asks and it's saved there for you.

```bash
npx jev-events watch bluesky
```

## `watch`

```txt
jev-events watch <source> [questions] [options]
```

Prints one row per item with each answer, its probability and how long Jev took, then a summary of requests, tokens and estimated spend when you press Ctrl-C. Messages Jev finds likely hateful (p ≥ 0.8) are hidden in the table.

### Sources

| Source | What it reads |
| --- | --- |
| `gmail` | New mail in your inbox, after `auth google` |
| `calendar` or `calendar:<calendar id>` | New and changed events in your Google Calendar, after `auth google` |
| `slack` or `slack:<channel>,<channel>` | Messages in the channels and DMs your Slack app is in, after `auth slack` |
| `twitch:<channel>` | Any public Twitch chat, no login needed |
| `bluesky` or `bluesky:<word>,<word>` | The Bluesky firehose, optionally only posts with these words |
| `stdin` | One item per line, e.g. `tail -f app.log \| npx jev-events watch stdin -a "..."` |
| `webhook` or `webhook:<port>` | POST `{"text": "..."}` to `http://127.0.0.1:8787/` |

### Questions

Every source gets sensible default questions, except `stdin` and `webhook`, which need at least one.

| Flag | |
| --- | --- |
| `-a, --ask "label=Question?"` | A yes/no question. The label is optional. Repeat for more. |
| `-c, --choice "Question?" -o a,b,c` | Pick one of these labels |
| `-r, --recipe email.urgent` | A built-in [recipe](/docs/recipes). Repeatable. |

### Options

| Flag | Default | |
| --- | --- | --- |
| `-f, --filter <regex>` | | Only judge items that match |
| `--min <0-1>` | 0.5 | Yes/no answers count from this probability |
| `--only` | | Only print items where something fired |
| `--rate <n>` | 8 | Jev requests per second |
| `--context <n>` | per source | Preceding items shown to Jev as context |
| `--lang <codes>` | | Bluesky only: posts in these languages, e.g. `en` |
| `-m, --model <id>` | `jev-latest` | The Jev model |
| `--json` | | Print JSON lines instead of a table |

### Examples

```bash
# Does any of your mail need a reply, or is it urgent? (the default questions)
npx jev-events watch gmail

# Only the events that matter or need preparation
npx jev-events watch calendar --only

# One Slack channel
npx jev-events watch slack:support

# What is chat doing, and is any of it hateful?
npx jev-events watch twitch:<channel>

# Your own question, only showing hits
npx jev-events watch twitch:<channel> --only \
  --ask "streamIssue=Is this about the stream's audio or video?"

# Pick a label
npx jev-events watch twitch:<channel> \
  -c "What is this message about?" -o "gameplay,streamer,other"

# Logs
tail -f app.log | npx jev-events watch stdin \
  --ask "Is this an error a human should look at?"

# Bluesky posts about a topic, as JSON lines
npx jev-events watch bluesky:typescript --lang en --json \
  --ask "Is this person asking for help?"
```

## `auth`

```bash
npx jev-events auth google
npx jev-events auth slack
npx jev-events auth twitch --client-id <id>
```

Connects an account once and saves it to `.jev-events/credentials.json`, which git ignores. The first time, `auth google` and `auth slack` walk you through creating your own Google OAuth client or Slack app, one step at a time. See [Google](/docs/integrations/google#sign-in), [Slack](/docs/integrations/slack#connect-a-workspace) and [Twitch](/docs/integrations/twitch#sign-in-a-bot).

| Flag | |
| --- | --- |
| `--client-id <id> --client-secret <secret>` | Google: use this OAuth client instead of asking |
| `--token <xoxb-…> --app-token <xapp-…>` | Slack: use these tokens instead of asking |
| `--client-id <id>` | Twitch: your Twitch app, required |
| `--scopes "<scope> <scope>"` | Google and Twitch: ask for fewer permissions |
